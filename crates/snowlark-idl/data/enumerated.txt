# Enumerated attributes (HTML §2.3.3): IDL attributes that reflect a content attribute limited to only known
# values. The IDL does not carry their keywords (they are in the HTML Standard's attribute tables), so they
# are listed here; the generator reflects them through Reflect. Reference: the C# engine's dom.js table.
#
# Format: Interface.attribute content-attribute | keywords | missing value default | invalid value default
# A keyword "a=b" is a non-canonical keyword a that maps to b; "=b" is the empty string mapping to b.
# Defaults: a keyword, "empty" for the empty string, or "null" (no default: the getter returns null).
